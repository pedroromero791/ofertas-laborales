EMPLEOSPERU.TECH V4 — MÁS OFERTAS POR CATEGORÍAS + JOOBLE API

QUÉ CAMBIA
- El sitio conserva el botón “Ver más ofertas” y puede mostrar hasta 12 por tanda.
- El actualizador consulta 4 búsquedas distintas por ejecución en Jooble, hasta 50 resultados por búsqueda.
- Las búsquedas rotan por día para cubrir Administración, Ventas, TI, Construcción, Salud, Educación, remoto, prácticas, ciudades y otras áreas.
- Se guardan hasta 200 ofertas, eliminando duplicados por URL.

IMPORTANTE SOBRE LA CUOTA
- Cada ejecución diaria usa hasta 4 solicitudes de API.
- Si la clave de Jooble tiene un límite de 500 solicitudes de por vida, son aproximadamente 125 ejecuciones diarias antes de agotar esa cuota.
- No ejecutes manualmente muchas veces sin necesidad. Si Jooble cambia las condiciones de la cuota, prevalecen sus condiciones actuales.

PASO 1 — ACTUALIZA LOS ARCHIVOS
Sube/reemplaza únicamente:
- index.html
- scripts/update_jobs.py
- .github/workflows/actualizar-empleos.yml

No publiques la API Key ni reemplaces jobs.json manualmente.

PASO 2 — SECRETO
En GitHub Settings → Secrets and variables → Actions debe existir:
JOOBLE_API_KEY

PASO 3 — PRUEBA
1. Ve a Actions → Actualizar ofertas de empleo.
2. Pulsa Run workflow una sola vez.
3. Abre el paso “Consultar Jooble y actualizar ofertas”.
4. Debes ver cuatro líneas de consulta y un resumen con los resultados únicos guardados.

La API Key nunca debe aparecer en los logs: GitHub la enmascara como ***.
