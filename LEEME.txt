EMPLEOSPERU.TECH — ACTUALIZACIÓN AUTOMÁTICA V2 (EXPERIMENTAL)

Esta versión amplía la búsqueda RSS pública a 12 categorías: administración, atención al cliente, ventas, producción, almacén/logística, construcción, diseño/marketing, informática, remoto, sin experiencia, prácticas y empleo general.

INSTALACIÓN
1. Descomprime el ZIP.
2. En tu repositorio pedroromero791/ofertas-laborales, sube y reemplaza estos archivos:
   - scripts/update_jobs.py
   - .github/workflows/actualizar-empleos.yml
3. No es necesario reemplazar index.html ni jobs.json para instalar esta actualización. El ZIP los incluye como referencia, pero conserva los que ya tienes si hiciste cambios propios.
4. Confirma los cambios en main.
5. Ve a Actions > Actualizar ofertas de empleo > Run workflow.
6. Abre el registro de ejecución y revisa los mensajes del paso de búsqueda. Después revisa https://empleosperu.tech/jobs.json.

QUÉ CAMBIA
- Busca en más categorías.
- Clasifica las ofertas según el título.
- Combina los enlaces descubiertos con las ofertas existentes para no borrarlas cada día por accidente.
- Conserva las ofertas manuales/curadas y elimina solo las descubiertas automáticamente que lleven más de 45 días sin reaparecer en resultados.
- Actualiza las acciones de GitHub a versiones más nuevas.

LIMITACIONES
- Es una prueba experimental mediante RSS público de Bing, no una API oficial de Computrabajo.
- Puede encontrar cero enlaces directos, repetir anuncios o no reflejar la vigencia real. No garantiza que haya nuevas vacantes cada día.
- No rastrea directamente páginas de Computrabajo ni elude restricciones. Para integración directa se necesita un método autorizado por la fuente.
- La ejecución programada puede retrasarse y, en repositorios públicos, GitHub puede desactivar workflows programados tras 60 días sin actividad.
